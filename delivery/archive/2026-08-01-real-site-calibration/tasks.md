# Tasks

## Mini-spec (class S, §2.2)

**Проблема.** Все числа и все дефекты проекта до сегодня получены на локальных
фикстурах. Первый прогон по настоящим сайтам показал две вещи, которых фикстуры
показать не могли:

1. **`robots_disallow` там, где сайт разрешает обход.** `docs.astro.build` упал за
   9 s с нулём страниц. Причина: `RobotFileParser.read()` ходит через `urllib` с
   дефолтным `Python-urllib/3.x`, сайт отвечает на такой UA **403**, а stdlib
   трактует 401/403 как `disallow_all`. В самом robots.txt написано `Allow: /`.
   Код при этом противоречил своей же шапке («4xx → allow»). На фикстурах не
   воспроизводится: для `127.0.0.1` robots не запрашивается вовсе.
2. **Видимое окно браузера висит весь attended-прогон**, хотя действия человека
   нужны в лучшем случае секунды. Сейчас `attended` решает сразу две разные вещи:
   «человек доступен» и «браузер `headless=False` на весь run».

**Готово, когда:**

- [x] R1: robots.txt читается нашим клиентом с честным UA; контракт из шапки
      восстановлен явно (4xx — правил не выдали, значит запрета нет; 5xx и сбой —
      проходим с логом); настоящий `Disallow` по-прежнему уважается — это инвариант
      проекта, и он **не размывается** (отдельный тест).
- [x] R2: видимость окна отвязана от `attended`. Окно появляется, только когда без
      человека нельзя (challenge, login-стена, подтверждение submit, необратимый
      шаг Tier 3), и прячется, как только надобность прошла.
- [x] R3: исключение названо честно — задачи-действия («заполни форму», «оформи
      заказ») открывают окно с начала, иначе к моменту handoff форма окажется
      пустой (перезапуск браузера теряет состояние страницы). Признак — уже
      существующий словарь `action_keywords`.
- [x] R4: доки: doc 03 (robots), doc 24 (семантика attended: «человек доступен» ≠
      «окно на весь прогон») — bump + changelog; concept `attended-mode` синхронизирован.
- [x] R5: результат real-site прогона (тайминги по стадиям, качество извлечения,
      найденные дефекты) — в `verify-report.md`.

**Вне scope.** Обход robots и обход anti-bot: остаются запрещёнными инвариантами
(`CLAUDE.md`, конституция). Для осознанного исключения на конкретном прогоне уже
есть per-run флаг `respect_robots: false` — это решение владельца, видимое в записи
прогона, и оно не меняет дефолт.
