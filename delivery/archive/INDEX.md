# Archive index

Что это: адресный указатель по `archive/`. Перед implement найди строки, чьи пути
пересекаются с твоим диффом, прочитай их уроки и сошлись на id в `plan.md`
(M/L) или `tasks.md` (S). Не применимо — напиши одной строкой почему.

⚠ **Индекс восстановлен ЗАДНИМ ЧИСЛОМ** при развёртывании `cqg@2.22`
(2026-08-17), а не на handoff каждой поставки, как требует правило. Значит
колонка уроков неполна по построению: где записи об уроке в поставке нет, стоит
`—`. Двадцать строк подряд с `—` — это не «ничего не узнали», а «разборы не
велись»; правило ведения ниже начинает действовать со следующей поставки.

Правила ведения:
- Строка добавляется на handoff, вместе с переносом поставки в `archive/`.
- Пути — префиксы от repo-root, в backticks. Только те, где жил урок.
- Урок — что мы **узнали о системе**, а не что сделали.
- Урок без id не считается: id — то, чем на него ссылаются.
- Поставка без урока — строка с `—` в колонке.
