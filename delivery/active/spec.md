# Spec — поставка `visit-memory`

## Задача владельца

Дословно: «нужно исправить известные баги и дыры и попробовать на других сайтах прогнать»,
затем «может ещё другие сайты погоняем, посмотрим косячки», «давай ещё вертикаль… чтобы прям
ультра боевой режим потестить» и «поправь пробелы сначала».

То есть поставка не «список задач из памяти», а **цикл**: замер журнала → починка → живой
прогон на новой вертикали → разбор находок → починка.

## Что было сломано (каждое подтверждено замером до правки)

| Дефект | Чем подтверждён |
|---|---|
| агент помнил, ГДЕ оказался, но не КУДА ходил | 4 прогона с повторами; `sports.ru` — 3 захода из 8 шагов бюджета |
| `word_count` брала модель | объявила 1380 слов при вдвое большем тексте, а число идёт в сравнение полноты |
| страницы-отказы (403, anti-bot с артиклем) шли в синтез как содержание | `seriouseats.com` 316 символов, `povarenok.ru` «403 Forbidden», `thekitchn.com` «verify you are **a** human» |
| комментарии читателей считались объёмом статьи | у победителя 581 слово из 3771 — обсуждение |
| прочитанная страница попадала в «не удалось открыть» | `sparkfun/returns` прочитан, потом 6 раз предложен и отбит |
| префиксное сопоставление врало на английском | `terms` → «Terminals», `store` → «Story»: три товарные ссылки получили счёт настоящей цели |
| справочные разделы были невидимы | `/support` и `/faq` по 3 балла, хотя условия доставки лежат именно там |
| слова с диакритикой рвались на обломки | `gründlicher` → «ndlicher»: ломался любой язык кроме RU/EN |
| немецкая задача поиска статьи опознавалась как `generic` | терялись блог-слуги, блок `article` и канонный синтез |
| пустая страница считалась содержанием | `chefkoch.de` — ноль текста и ноль ссылок, скриншот белый |
| объявленный бюджет статьи был недостижим | excerpt ровно 8000 у двух живых статей из трёх при объявленных 12000 |
| промах на `food52` | раздел `/food/baking` получал **ноль**: `bake` не связывалось с `baking` |

## Критерий приёмки

1. Ноль повторных заходов на URL в живых прогонах.
2. Заглушки (403, anti-bot, 404, пустые) в синтез не попадают.
3. Факты подтверждены цитатами со страниц.
4. Ответ на языке запроса — проверить на третьем языке (немецком).
5. Каждая правка формулы навигации проверена **двумя** контролями: 8 снятых русских страниц
   и английский кейс — дифф по обоим.

## Acceptance examples

Конкретные вход → выход, все взяты из живых записей и подтверждены прогонами:

| id | Вход | Ожидаемый выход |
|---|---|---|
| A1 | страница A редиректит на B, модель второй раз предлагает A | отказ «already attempted»; A **не** попадает в «не удалось открыть», если B прочитан |
| A2 | `povarenok.ru` отдаёт «403 Forbidden» (19 символов) | статус `error`, страница не идёт в синтез |
| A3 | `thekitchn.com`: «Please verify you are **a** human» | статус `captcha` (не `ok`), attended-пауза возможна |
| A4 | `chefkoch.de`: 0 слов и 0 ссылок после `networkidle` | статус `error` |
| A5 | `vercel.com`: 0 слов, но 164 ссылки | статус `ok` — SPA не трогаем |
| A6 | задача «shipping and returns», ссылка «Spring **Terminals**» | тег `task-kw` **не** присваивается |
| A7 | та же задача, ссылка «Return Policy» | тег `task-kw` присваивается (`returns` ≡ `return`) |
| A8 | та же задача, ссылка `/support` на внутренней странице | тег `help-desk`, счёт > 3 |
| A9 | задача «bake bread», ссылка «Baking» | тег `task-kw` (было: ноль) |
| A10 | немецкая задача «Finde eine Anleitung…» | интент `content_search`; слова `anleitung`, `brot`, `backt` — целые |
| A11 | статья длиннее любого cap | `main_text_excerpt` ровно `ARTICLE_TEXT_CAP`, `word_count` считан кодом по полному тексту |
| A12 | три немецких сайта, задача по-немецки | ответ и обоснование сравнения **по-немецки**, ноль повторных заходов |

## Границы

- Не пилить логику под конкретный сайт (правило владельца, повторено дважды).
- Anti-bot не обходить — признаки читаются из того, что сайт написал сам.
- Живые прогоны годятся для проверки **маршрута**, не для счётных критериев: на машине
  активен VPN-тоннель, Chromium встаёт на 16–30 s примерно на трети загрузок любого хоста.
