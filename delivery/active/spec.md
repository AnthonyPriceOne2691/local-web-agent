# Spec: чистка легаси-долга, вскрытого развёртыванием контура

## Problem

Развёртывание канон-стека (2026-07-27) вскрыло долг, который до этого был
невидим: гейты его показали, но чинить в bootstrap-поставке было нельзя — она
и так вышла на 71 файл. Долг заморожен в тающих списках и baseline'ах, то есть
**новый код им не заражается, но старый живёт с ним**:

| Долг | Масштаб | Почему это важно |
|---|---|---|
| Молчаливые `except` | 20 сайтов в 10 модулях `app/` | Ошибка исчезает бесследно: диагностика падений сводится к угадыванию (CQG §1.5) |
| Ошибки типов за `ignore_errors` | 39 ошибок в 8 модулях | mypy на этих модулях выключен целиком — новые ошибки типов там тоже не увидим |
| ESLint warnings | 17 (import/order, non-null assertion, сложность) | Ратчет держит рост, но фронт остаётся с шумом |
| Нет secrets-scanner | — | Единственный слой безопасности в git — `.gitignore` и внимательность |
| Формат Python-кода не прибит | 68 файлов вне `ruff format` | Гейт формата не подключён, стиль дрейфует |

## Users / stakeholders

Владелец проекта (Anton) и любой агент в следующих сессиях: и тот, и другой
читают падения по логам и полагаются на гейты как на правду о состоянии кода.

## In scope

- Осмысленное логирование (или явный `# silent-ok:` с причиной) во всех
  молчаливых `except` внутри `backend/app/**`.
- Исправление 39 ошибок типов → снятие всех `[[tool.mypy.overrides]]`.
- ESLint: 0 warnings без правки baseline вверх.
- Подключение secrets-scanner в pre-commit + CI.
- `ruff format` по проекту + `.git-blame-ignore-revs` (отдельный коммит).
- Пере-снятие baseline'ов **вниз** после чистки.

## Out of scope

- `scripts/spike/**` — Phase 0 артефакт, по CLAUDE.md исключён из стандартов
  (3 молчаливых `except` там остаются в baseline).
- Разбиение сложных функций (C901/PLR09xx в 10 модулях) — это рефакторинг
  архитектуры оркестратора, отдельная поставка со своим риском регрессии.
- mypy `strict` (146 ошибок в 40 модулях) — следующий шаг после этой чистки.
- Функциональные изменения поведения агента: правки не должны менять ни один
  наблюдаемый сценарий.

## Acceptance (observable)

- [ ] `silent_except_baseline.txt` содержит только `scripts/spike/**`
- [ ] `pyproject.toml` не содержит `[[tool.mypy.overrides]]`; `mypy app` зелёный
- [ ] `npx eslint src` → 0 errors, 0 warnings; baseline переснят вниз (17 → 0)
- [ ] secrets-хук проходит `pre-commit run --all-files` и стоит в `quality.yml`
- [ ] `ruff format --check` зелёный на всём проекте
- [ ] 191 тест зелёный; smoke S1–S5 зелёные; `merge_guard.sh` 5/5 на слитом состоянии

## Non-functional

- Ни одно изменение не меняет поведение: логирование добавляет вывод, но не
  управляющий поток; правки типов — аннотации и явные проверки `None`.
- Стилевой коммит (`ruff format`) изолирован и попадает в
  `.git-blame-ignore-revs`, чтобы не зашумлять blame.

## Open questions

  которые показала раскатка контура»).
