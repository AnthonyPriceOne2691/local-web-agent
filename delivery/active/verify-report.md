## Product oracle — приёмка U1–U8

### U1 — единый визуальный язык ✅

Три стеклянных слоя (чаты · разговор · инспектор) над насыщенным градиентным
полотном: полупрозрачная заливка, размытие с подъёмом насыщенности, светлая кромка
изнутри и мягкая тень. Light и dark обе полноценные, `prefers-reduced-motion`
уважается, фон сознательно не анимирован.

**Дефект, который поймал только скриншот.** Первая версия полотна была бледной
(oklch 93–97 %) — слою нечего размывать, и панели читались как белые плашки на
белом. Сборка и линтеры этого показать не могут. Исправлено: полотно углублено и
насыщено, а на светлой теме добавлена внешняя тёмная линия кромки
(`0 0 0 0.5px`) — без неё панель сливается с фоном.

**Второй дефект, найденный при разборе.** Пузырь сообщения пользователя
переиспользовал стиль кнопки и вместе с ним получал подсветку по hover и сдвиг по
нажатию. Сообщение не должно реагировать на клик → введена поверхность
`accent-surface` без интерактивных состояний.

### U2 — ноль русского и ноль внутренних терминов ✅

| Было (лексика кода) | Стало |
|---|---|
| `running_tools` · `comparing` · `not_found` | Visiting sites · Comparing sites · Nothing found |
| `Runs (3)` · `intent` | Sites visited · 3 · «Looking for an article» |
| `extract_now` · `OBSERVE` · `SYNTHESIZE` | Pulled the answer from this page · Read the page · Wrote up the findings |
| `Dimensions · content_completeness` | Side by side · «Compared on how complete the content is» |
| `winner` · `rankings` · `narrative` | Best of the bunch · How they scored · In short |
| `3/10 pages` · `loading <id>…` | 3 of 10 pages read · Loading what the agent saw… |
| `HTTP 409 run_in_progress` | «Another research run is still going. Wait for it, or stop it first.» |

Русские строки убраны не только с фронта (паузы, тумблер, примеры), но и из
бэкенда, откуда часть текста приходит готовой: заметки о шагах
(`crawl_site <url> (1/4)`, `Tier 2 требует подтверждения — пропущено`), ответы в
чат, `note`-хуки реестра и результат экспорта
(`Экспортировано в Google Docs (облако)`).

### U3 — словарь в одном месте ✅

`frontend/src/copy.ts` (перевод значений) и `backend/app/research/phrasing.py`
(текст, который сочиняет сервер). Неизвестное значение падает в `humanizeKey`
(snake_case → фраза), поэтому следующий статус с бэкенда не просочится ключом.

**Правка scope объявлена заранее** (в `tasks.md`): бэкенд входит в поставку в части
**строк**. Альтернатива — парсить строки на клиенте — была бы хаком, который
сгниёт при первом изменении формата.

### U4 — доступность ✅

Строки чатов стали настоящими `button` с фокус-кольцом (были кликабельные `div`),
системный `confirm()` заменён подтверждением внутри интерфейса, добавлены
`aria-label` / `aria-expanded` / `aria-pressed` / `aria-label` у поля ввода.
Нумерация шагов начинается с 1: `step.index` — индекс бэкенда, у людей списки с единицы.

### U5 — `App.tsx` только композиция ✅

`useSession` (состояние + `makeActions`) и `useSessionStream` (SSE — единственное
место с ресурсом времени жизни). Закрывает пункт бэклога про UI-рефактор.
Разделение произошло не по вкусу: eslint-ратчет (`max-lines-per-function` 80)
дважды показал, что хук слишком большой, и заставил развести ответственности.

### U6 — гейты ✅

`tsc --noEmit` + `vite build` · eslint **0 warnings** (ратчет не сдвинут) ·
prettier · 227 pytest · ruff · ruff format · mypy strict (87 модулей) ·

### U7 — проверено глазами ✅

Скриншоты на живом API, 1440×900 @2x, оба режима: пустой экран, чат с результатом,
вердикт сравнения, раскрытая карточка сайта. Данные подставлены перехватом запросов —
модели для проверки вида не нужны, а вид проверяется настоящим рендером.

Побочно скриншоты подтвердили работу гуманизации ошибок: сломанный маршрут в
скрипте дал реальный 404, и в интерфейсе появилось «That chat is gone — it may have
been deleted» вместо `HTTP 404`.
