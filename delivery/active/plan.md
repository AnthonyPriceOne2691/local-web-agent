# Plan — поставка `visit-memory`

## Порядок работы

1. **Замер журнала прогонов** (`data/runs/app.db`, 125 записей) — не список из памяти, а то,
   что видно в записях: повторы, пустые блоки, ложные статусы.
2. Починка найденного, каждая правка с тестом по **реальной записи** прогона.
3. Живой прогон на новой вертикали → разбор → починка. Три захода: англоязычная кулинария,
   магазины электроники, немецкие сайты с задачей по-немецки.
4. Закрытие названных пробелов (V15, V23, V38) — по требованию владельца «поправь пробелы».

## Приём, который окупился трижды

Перед живым прогоном считать очередь кандидатов **офлайн** на снятых страницах
(`inspect_queue.py` / `score_pages.py`): оракул детерминирован, не зависит от сети и
показывает, **был ли у агента шанс**. Самая дорогая находка серии (диакритика) нашлась именно
так — до запуска модели.

## Rejected alternatives

Отвергнуто **числами**, не вкусом — переоткрывать без нового замера нельзя:

| Что предлагалось | Почему отвергнуто |
|---|---|
| **Поднять `ARTICLE_TEXT_CAP` до 12000** | блок сравнения трёх сайтов вырастает до ~13 450 токенов на русском, с ответом 4096 это 17 546 против `num_ctx` 16384 — переполнение. Возможно только вместе с `WIDE_NUM_CTX`, то есть отдельным решением с ценой по RAM |
| **Правило «частотное слово не тема» (idf-подобное)** | замер опроверг гипотезу: `home` на `food52` совпало лишь с 6 % ссылок — правило не сработало бы. Настоящей причиной был разрыв `bake` ↔ `baking` |
| **Резать пустую страницу по одному признаку «нет текста»** | выпал бы весь SPA-сценарий: у живого SPA пустым бывает только текст, ссылки есть всегда (`vercel.com` 111 слов при 164 ссылках). Признак сделан парным |
| **Считать бюджет страниц (G-H1) по `attempted`** | бюджет про прочитанное, а не про попытки; граница закреплена тестом, чтобы «наивная» починка падала |
| **Словари под вертикаль** («промо», «мусорные» карты sitemap) | правило владельца; удаление проверено замером — все критерии удержались |
| **Удалять узел комментариев из DOM** | клон вне DOM теряет layout, и `innerText` выродился бы в `textContent` для всей страницы. Текст **вычитается**, узел остаётся |
| **Ретрай синтеза** | удвоил бы самую дорогую стадию (178–227 s) |
| **Показывать на демо живой прогон реального сайта** | 7 мин 38 s, из них модель 97 s — остальное сеть под VPN. Заменено витриной готовых прогонов |

## Что осталось названным, но не сделанным

- **Редирект-алиасы живьём не подтверждены**: сайты трёх прогонов внутри обхода не
  редиректили. Механика держится юнит-тестом.
- **«NO BAKE» остаётся тематическим** — формула не понимает отрицания; различить может
  только модель, читая подпись. Раздел выпечки теперь стоит в окне рядом.
- **`/support` и `/faq` найдутся не везде**: имя раздела может не содержать слов задачи.
