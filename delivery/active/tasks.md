# Tasks — found-fixes (починка найденного испытаниями)

**Задача:** закрыть то, что испытания T-3f/T-3h нашли и назвали, но не починили. Решение
владельца 05.08: «давай мёрдж, а потом чини найденное».

Журнал: [doc 26 § T-3h](../../docs/26-real-site-trials.md). Правило поставки то же:
**замер вперёд правки**, и у каждой правки названо, чего она не лечит.

- [x] **C1** бюджет синтеза измерен по **28 прогонам** из БД (медиана 92.5 s, максимум
      **250.2 s** при общем 300 s, 8 из 28 выше 60 %); при шуме wall-time ±25 % тяжёлый
      случай перешагивает бюджет закономерно → `synth_timeout_s = 420` у синтеза и
      `compare`. **Ретрай отклонён числами** (удвоил бы 178–227 s), цена решения названа:
      подвисший Ollama распознаётся за 7 минут вместо 5.
- [x] **C2** прочитанное больше не выбрасывается при падении синтеза: прогон остаётся
      `failed` (сайт без фактов не должен попасть в сравнение), но в записи появляется
      результат со списком прочитанных страниц. Раньше от 4 страниц и найденной статьи не
      оставалось следа.
- [x] **C3** глубина перестала быть тихой: `--max-depth` у CLI `research`, поле `max_depth`
      у `POST /sessions`, **действующее число** в ответе и в строке старта. Приоритет:
      аргумент плана > сессия > процесс.
- [x] **C4** выбор **внутри** обучающего раздела починен: эталон на хабе
      `legalbet.ru/shkola-bettinga/` **#26 → #1** (38 → 46). Разложение показало, что
      различие с соседями было **единственным** и работало против ответа (короткая точная
      подпись не даёт `headline`), а слов задачи совпало одинаково — 2 против 2. Правило без
      параметров: различает то слово задачи, которого **нет** в контексте страницы; таких
      ссылок на хабе 5 из 212. Контроли: три корня без изменений, доля тематических в top-10
      не изменилась ни на одной из 8 страниц, 401 тест.
- [x] **C4.1** три ограничения правила поставлены **замером, а не осторожностью**: пустой
      контекст; контекст без слов задачи (иначе на корне `championat` статья раздела
      вылетала из top-10); главная страница (иначе хаб на корне `legalbet` съезжал #1 → #7).
      Оба регресса были пойманы оракулом **до** коммита.
- [x] **C4.2** починена **третья** ошибка того же вида в самом оракуле: полный список
      считался без контекста страницы, и колонка места врала. Замер без этого был бы неверен.
- [x] **C5** доки: 15 v0.9 · 16 v0.11 · 24 v0.15 · 26 v0.13 · индекс v2.0; версии в шапке,
      индексе и changelog совпадают.
- [x] **C6** гейты: 398 тестов, ruff, format, mypy strict (93 модуля), размер модулей,
      import-linter. Новые тесты писались до правок и падали на старом коде.
