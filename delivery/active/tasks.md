# Tasks

## Mini-spec (class S, §2.2)

**Проблема (взгляд UI/UX, а не только «перекрасить»).**

1. **Язык смешан.** Паузы, тумблер attended и примеры задач — по-русски, остальное
   по-английски. Требование владельца: только English.
2. **Наружу торчит внутренняя лексика.** `runs`, `intent`, `running_tools`,
   `not_found`, `extract_now`, `OBSERVE`, `Dimensions`, `rubric`, `loading <id>…`,
   `pages_visited/max_pages`. Это словарь бэкенда, а не язык пользователя: подписи
   требуют знания устройства проекта.
3. **Визуал бессистемен.** Тёмный сайдбар рядом со светлыми панелями, плоские
   slate/blue плашки, восемь оттенков границ, нет тёмной темы, нет фокус-состояний.
4. **Доступность.** Строка сессии — кликабельный `div` (не фокусируется с
   клавиатуры), удаление через `confirm()`, у иконок-кнопок нет доступных имён.

**Готово, когда:**

- [ ] U1: единый визуальный язык «жидкое стекло»: слои полупрозрачных поверхностей
      с размытием и тонкой светящейся кромкой поверх живого градиента; light и dark
      обе полноценные; `prefers-reduced-motion` уважается.
- [ ] U2: **ноль русского текста** в `frontend/src` и ноль внутренних терминов в
      подписях. Технические значения показываются человеческим языком (`extract_now`
      → «Pulled the answer from the page»), а не сырыми ключами.
- [ ] U3: словарь формулировок — **одно место** (`copy.ts`), а не строки по
      компонентам: иначе следующий статус с бэкенда снова просочится сырым.
- [ ] U4: доступность: строки сессий — настоящие кнопки с фокус-кольцом, у
      иконок-кнопок `aria-label`, удаление — с подтверждением в интерфейсе, не
      системным `confirm()`.
- [ ] U5: `App.tsx` — только композиция; вся логика SSE/состояния в хуке
      (закрывает пункт бэклога про UI-рефактор).
- [ ] U6: гейты зелёные: `tsc --noEmit` + `vite build`, eslint **0 warnings**
      (ратчет), prettier, лимиты размера файлов.
- [ ] U7: проверено **глазами** — скриншоты light и dark на живом API, а не только
      «собралось».
- [ ] U8: doc 17 (UI screens) — bump + changelog; описан визуальный язык и словарь.

**Вне scope.** Бэкенд, API-контракты, схемы; новые экраны и функции; i18n-каркас
(язык один — English, по требованию); автотесты UI (их нет и в этой поставке не
появляются — сказано прямо в STATUS).
