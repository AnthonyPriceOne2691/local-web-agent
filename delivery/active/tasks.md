## Mini-spec (class S, §2.2)

**Проблема.** Два последних пункта долга гейтов, оба про `scripts/`: гейт-скрипты не
покрыты `mypy` и заморожены по сложности (`delivery_check.main` — **47** при пороге 10,
`okf_sync_gate.main` — 25, `okf_validate.validate_bundle` — 17, `stack_selftest.main` —
15). Это код, который решает, пройдёт ли поставка: его ошибка не роняет прогон, а
**молча пропускает** нарушение. При этом тестов у него не было вообще.

Отдельно: список заморозок сложности в backend перестал соответствовать реальности —
часть модулей давно не нарушает пороги, а заморозка висит. Ратчет, который не тает,
врёт о размере долга.

**Готово, когда:**

- [x] S1: `mypy --strict` на `scripts/` зелёный (было 7 ошибок в 2 файлах). Правки —
      настоящие: `Rule` вместо dict с разнородными значениями (у dict тип полей
      схлопывается в `object`, и `rule["find"](…)` не проверялся), `end_lineno` может
      быть `None`, переменная цикла больше не затеняет `date`.
- [x] S2: гейт покрыт хуком `mypy-scripts` (pre-commit → CI через `--all-files`).
      Флаги в `entry`, а не в конфиге: у корня нет своего pyproject, а backend-конфиг
      исключает `scripts/`.
- [x] S3: **характеризационные тесты написаны ДО разбора** — 22 кейса
      (`test_delivery_check_gate.py` 12, `test_gate_scripts.py` 10). Гейты
      вызываются процессом: пиннятся exit code и текст сообщений, а не внутренности.
- [x] S4: сложность разобрана у всех четырёх скриптов — канонные пороги без единой
      заморозки. `main()` теперь только собирает контекст и печатает; каждая проверка
      — функция, возвращающая `(errors, warnings)`.
- [x] S5: `delivery_check` получил `--root`, иначе его нельзя прогнать ни на чём,
      кроме самого репозитория (и, значит, нельзя проверить).
- [x] S6: заморозки сложности растоплены: из `scripts/` сняты все четыре, из backend —
      `vision_batch`, `sitemap`, `snapshot`, `compare_synthesizer` (больше не нарушают).
- [x] S7: скрипты после разбора проверены на **настоящих** данных: `stack_selftest`
      на `Prepare/` — 41 блок, 0 провалов; `okf_validate`/`okf_sync_gate`/
      `delivery_check` на репозитории — вывод прежний.
- [x] S8: doc 18 v0.4 — mypy-контур и правило «новый гейт = проверки-функции».
- [x] S9: гейты зелёные: `pytest` **292**, ruff, ruff format, mypy strict (app +
      scripts), module-size, pre-commit `--all-files`, `delivery_check`, `okf_sync_gate`.
